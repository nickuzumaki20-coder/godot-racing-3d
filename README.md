# 🏎️ Godot Racing 3D - AAA Open World Racing Game

**Godot Engine 3.6 | 3D Open World | Single Player**

Полностью готовый, игрaбельный проект racing game с открытым городом в стиле **Need for Speed Underground / Midnight Club**.

## 🎮 Особенности

- ✅ **Полностью рабочий проект** - запускается сразу после открытия
- ✅ **3D Open World город** - дороги, перекрёстки, гараж, автосалон
- ✅ **Реалистичная физика машины** - ускорение, инерция, трение, дрифт
- ✅ **10+ миссий** - гонки, time trial, полиция, дрифт, доставка
- ✅ **AI NPC** - машины с маршрутами и поведением
- ✅ **Гонки** - таймер, чекпоинты, позиция, финальные награды
- ✅ **Экономика** - деньги, покупка машин, улучшения
- ✅ **Гараж и автосалон** - выбор и покупка машин
- ✅ **Полный UI** - меню, HUD, настройки, сохранения
- ✅ **Third-person камера** - плавное сглаживание
- ✅ **Система сохранений** - JSON, полный прогресс
- ✅ **Без TODO и заглушек** - чистый, готовый код

## 📋 Требования

- **Godot Engine 3.6+** (не 4.x)
- **Операционная система:** Windows, macOS, Linux

## 🚀 Запуск проекта

1. **Открыть проект в Godot 3.6**
   ```bash
   # Откройте папку как проект в Godot 3.6
   # File → Open Project → godot-racing-3d
   ```

2. **Запустить игру**
   - Нажмите `F5` или кнопку "Play"
   - Вы попадёте в главное меню

3. **Новая игра**
   - Нажмите "New Game"
   - Выберите машину
   - Начните с первой миссии

## 🏗️ Архитектура

### Менеджеры (Autoload)
- **GameManager** - главный контроллер, состояние игры
- **SaveManager** - загрузка и сохранение JSON
- **MissionManager** - система миссий и прогресс
- **CarManager** - парк машин, характеристики, улучшения

- **UIManager** - управление UI элементами

- **Race System** - таймер, чекпоинты, позиция
- **AI System** - NPC маршруты и поведение

## 🔧 Модификация и расширение

Проект полностью масштабируем:

### Добавить новую миссию
1. Отредактируйте `Scripts/Managers/MissionManager.gd`
2. Добавьте данные миссии в массив `missions`
3. Создайте сцену гонки в `Scenes/Race/`

### Добавить новую машину
1. Отредактируйте `Scripts/Managers/CarManager.gd`
2. Добавьте машину в массив `cars`
3. Создайте 3D модель в `Assets/Models/`

### Настроить физику
- Измените параметры в `Scripts/Car/CarPhysics.gd`
- Ускорение, трение, инерция, макс скорость
